📲 Mobile OTP Delivery & SMS Gateway Info

Why do OTPs appear directly on the website?
Browsers running on your computer or phone cannot directly talk to cellular telecom networks (Airtel, Jio, Vi, BSNL). In production, an SMS is sent by a secure backend server through an SMS Gateway API.

How Real Cellular SMS Delivery Works:
  • Google Firebase Phone Auth (Recommended): Free tier provides up to 10,000 real verification SMS/month with zero initial telecom contracts.
  • Fast2SMS / MSG91 (India DLT): Direct Indian SMS route (~₹0.15/SMS), requires TRAI DLT Sender ID approval (e.g. CRPLSE).
  • Twilio Verify API: Global carrier standard for international patients.

The current Simulated Notification Banner gives you an interactive, zero-cost preview with one-click Auto-Fill and Copy Code buttons so you can test all patient features instantly.
